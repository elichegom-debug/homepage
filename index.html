주요 특징 및 특기사항

  • 오브젝트 풀링(Object Pooling) 최적화 수천 개의 투사체가 등장하는 탄막 슈팅 환경에서 Garbage Collection 스파이크를 방지하기 위해 커스텀 오브젝트 풀 매니저를 구현하여 프레임 드랍을 60fps로 방어했습니다.
  • FSM (유한 상태 기계) 기반 AI 설계 적 몬스터들의 패턴(대기, 추적, 공격, 도망)을 FSM 패턴으로 구현하여, 코드의 가독성을 높이고 새로운 몬스터 추가 시 유지보수 비용을 크게 줄였습니다.
  • Scriptable Object 활용 데이터 관리 아이템 스탯, 몬스터 정보 등을 하드코딩하지 않고 Scriptable Object로 분리하여 기획자와의 협업 효율성을 극대화했습니다.

제네릭 오브젝트 풀러

게임 내에서 잦은 생성/삭제가 일어나는 총알(Projectile)과 파티클 이펙트를 관리하기 위해 Generic 형태의 Object Pool을 구현했습니다.

필요할 때 Instantiate를 호출하지 않고, 비활성화된 큐(Queue)에서 꺼내어 재사용(Reuse)함으로써 메모리 파편화를 막고 성능 최적화를 이루어낸 핵심 시스템입니다.

ObjectPoolManager.cs
public class ObjectPoolManager<T> : MonoBehaviour where T : Component
{
    private Queue<T> poolQueue = new Queue<T>();
    private T prefab;

    // 풀 초기화
    public void Initialize(T objectPrefab, int count)
    {
        prefab = objectPrefab;
        for (int i = 0; i < count; i++)
        {
            T newObj = Instantiate(prefab);
            newObj.gameObject.SetActive(false);
            poolQueue.Enqueue(newObj);
        }
    }

    // 오브젝트 대여
    public T Get()
    {
        if (poolQueue.Count > 0)
        {
            T obj = poolQueue.Dequeue();
            obj.gameObject.SetActive(true);
            return obj;
        }
        // 풀이 부족할 경우 추가 생성
        T newObj = Instantiate(prefab);
        return newObj;
    }
}
